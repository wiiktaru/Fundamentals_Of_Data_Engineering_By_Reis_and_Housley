# Fundamentals of Data Engineering – Reis & Housley

## Project overview

This repository is a personal learning portfolio built around the book *Fundamentals of Data Engineering: Plan and Build Robust Data Systems* by Joe Reis and Matt Housley.

I chose this book because it provides a comprehensive foundation for understanding the principles, practices, and lifecycle of data engineering.

The goal is not simply to summarize the book, but to actively engage with its concepts, visualize relationships between topics, and develop a deeper understanding of the data engineering discipline.


## Objectives

- **Visualize knowledge:** Transform topics into mind maps that make concepts easier to understand and remember
- **Build conceptual understanding:** Identify relationships between different components of the data engineering ecosystem
- **Document my learning journey:** Maintain a structured record of what I learn throughout the book
- **Reinforce learning:** Use mind mapping and note-taking as active learning techniques to strengthen knowledge retention


## Repository structure

The repository is organized around the chapters and themes covered in *Fundamentals of Data Engineering: Plan and Build Robust Data Systems*. It follows the book's structure, with dedicated mind maps and learning notes for its chapters and key topics.


## Technologies used

- **draw.io:** Creating visual mind maps to organize and connect concepts
- **Visual Studio Code:** Writing documentation, managing repository files, and organizing learning materials
- **Git:** Version control for tracking changes and managing updates
- **GitHub:** Hosting the repository and making the learning portfolio publicly accessible
